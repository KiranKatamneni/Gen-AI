# 🧠 Gen-AI

This repository is a collection of hands-on NLP (Natural Language Processing) notebooks, showcasing both fundamental and advanced deep learning techniques. It is designed as a learning playground to help you master:

- 🧹 **Text Preprocessing**: Tokenization, lowercasing, stopword removal using NLTK.
- 🧮 **Vectorization Techniques**: Bag of Words, TF-IDF.
- 🧠 **Word Embeddings**: Using embedding layers and pretrained techniques like Word2Vec.
- 🔁 **Recurrent Neural Networks**: Build and train RNN models including SimpleRNN, GRU, and LSTM.
- 📊 **Data Exploration**: Understand your dataset before modeling.
- 🤖 **Sequence Modeling**: Apply deep learning on time-series and NLP tasks.
- 🧪 **Spam Detection**: Practical notebook using a real SMS spam dataset.

Whether you're new to NLP or strengthening your deep learning skills, this repo is your companion.

---

## 📂 Contents

- `7_Text Preprocessing Stopwords With NLTK.ipynb` – Text preprocessing with NLTK.
- `Bag Of Words Practicals.ipynb` – Bag of Words model implementation.
- `Data_exploration_in_NLP.ipynb` – EDA for NLP datasets.
- `Embedding.ipynb` – Word embedding methods.
- `GRU_RNN.ipynb` – GRU-based RNN for sequences.
- `LSTM_RNN.ipynb` – LSTM model for long dependencies.
- `Neural_networks_0.ipynb` – Intro to neural networks.
- `SimpleRNN.ipynb` – Build a simple RNN from scratch.
- `spam.csv` – Dataset for spam detection.
